# TSX

**Two Avalanche L1 chains, one native coin.** Built by 3S Game Studio OÜ in Tallinn, Estonia.

TSX is a pair of EVM chains that share one coin. Horizon is open to every builder. Bastion is open only to approved ones. Both charge fees in TSX.

## Networks

Official chain IDs, RPC endpoints, and verified contract addresses are in [TSX-Blockchain/networks](https://github.com/TSX-Blockchain/networks). The live source of truth is [tsx.network/networks.json](https://tsx.network/networks.json).

| Network | Chain ID | Access | RPC | Explorer |
| --- | --- | --- | --- | --- |
| **TSX Horizon** | `455` | Open deployment and use | `https://horizon.tsx.network/rpc` | [scan.tsx.network/horizon](https://scan.tsx.network/horizon) |
| **TSX Bastion** | `454` | Curated deployment, open use | `https://bastion.tsx.network/rpc` | [scan.tsx.network/bastion](https://scan.tsx.network/bastion) |
| **TSX Testnet** | `445` | Free testing with faucet | `https://testnet.tsx.network/rpc` | [scan.tsx.network/testnet](https://scan.tsx.network/testnet) |

The coin is TSX on every chain, with 18 decimals. Start on Testnet, move to Horizon when you are ready, and write to builders@tsx.network if your product belongs on Bastion.
