# TSX

**Two Avalanche L1 chains, one native coin.** Built by 3S Game Studio OÜ in Tallinn, Estonia.

TSX is an Avalanche L1 Subnet-EVM network designed for games, studios, and builders who need fast finality, predictable fees, and room for large transactions.
